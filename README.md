# DumLRM

A reasoning model built from scratch: Qwen3 architecture, evaluation, inference
scaling, self-refinement, GRPO, and distillation. The chapter notebooks live in
`src/dumlrm/chapters/`.

## Status

The theoretical portion is complete (chapters 2 through 8).

The trained models have not been uploaded yet. Once training is finished, the
checkpoints will be uploaded and listed in [my_view.md](my_view.md).

## Notes

- Model weights, datasets, checkpoints, and run logs are not tracked in Git.
- Shared helpers used by the notebooks are consolidated in
  `src/dumlrm/chapters/reasoning_utils.py`.
